## Direction contract

**THESIS:** Show how coordinate-bearing Markdown becomes a paged geographic story, with an operable map as proof and concrete source examples as the next step.

**OWN-WORLD:** Editorial travel journal: warm paper, pine, terracotta emphasis, sans-serif headings, serif prose, restrained borders, and real Leaflet maps.

**STORY:** Introduction → live demo → features → interactive playground → source examples and configuration table → Obsidian installation, then React/Docusaurus integration → FAQ. Example journeys are illustrative, not customer endorsements or travel advice.

**FIRST VIEWPORT:** Sticky navigation above an asymmetric headline/lede row. The primary action sits with the lede; a large, captioned live map spans the content width below. Narrow layouts stack the copy and retain an operable map.

**FORM:** User-confirmed code-first direction. No concept-seed key or ranked candidate position was recorded; do not invent one.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
