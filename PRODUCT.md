# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The introduction site prioritizes Obsidian note authors, with React and Docusaurus
integration paths for developers. Confirmed during the September 2026 redesign.

## Product Purpose

Turn coordinate-bearing Markdown notes into paged geographic stories. The product
contract remains in SPEC.md; this record describes the public website's audience.

## Capabilities and Constraints

One StoryMapConfig connects the Obsidian desktop plugin, React renderer, and Remark
publishing adapter. Keep the implementation and non-goals in SPEC.md authoritative.
The site supports English and Traditional Chinese. Demonstrations use the real renderer.

## Evidence on Hand

site/src/stories.ts contains illustrative stories, not customer evidence or travel advice.
Package APIs, README files, and tests are the sources for capability claims.

## Brand Commitments

Geo Story Map. Clear, practical language; Taiwanese Traditional Chinese terminology.
