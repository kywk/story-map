# StoryMap 0.3.0

Released 2026-09-29. The [Obsidian plugin release](https://github.com/kywk/story-map/releases/tag/0.3.0)
and the [npm packages](#npm-packages) are available. The private workspace root, site and
example package versions are independent.

## Highlights

- Six coordinated map and content themes: `auto`, `light`, `dark`, `vintage`, `cyber`
  and `atlas`. Obsidian defaults to `auto`, following the native host theme; fixed
  themes preserve authored palettes across hosts.
- Card and full layouts, card alignment and optional width/height ratios, left/right
  full content placement, and narrow-screen vertical fallback.
- Full-layout floating navigation and page counter, with map focus offset to keep
  the active marker clear of the content panel. Theme and layout changes preserve
  the Leaflet instance.
- Full layouts resolve linked notes as full Markdown content regardless of
  `noteDisplay`, without duplicating frontmatter titles or media.
- Redesigned English/Traditional Chinese project site with interactive examples,
  settings reference, copyable source and official community-plugin installation.
- GitHub Pages pull requests run validation; deployment remains restricted to main.

## Upgrade notes

Existing YAML documents receive parser defaults for the new theme and layout fields.
The source schema identifier remains `storymap/v1`. Direct TypeScript construction of
`StoryMapConfig` requires `map.theme` and `layout`. To retain a fixed light card layout,
add the following fields alongside the existing map settings and slides:

```ts
map: {
  // Keep your existing map settings.
  theme: 'light',
},
layout: {
  mode: 'card',
  card: { align: 'left' },
  full: { side: 'right', contentRatio: 0.5 },
},
```

Alternatively, use the core parser/schema to apply defaults. `layout` remains a
document-only setting; only `map.theme` is added to Obsidian plugin defaults.
The plugin remains desktop-only and requires Obsidian **1.8.7 or newer**.
Install or update it through Settings → Community plugins → Geo Story Map.

## Known limitations

- Blue Topaz can override bold text with a light `!important` color, reducing contrast
  in Atlas. This release does not fix that host CSS conflict. See the
  [Atlas comparison](../acceptance/2026-09-28-atlas-comparison.md).
- Map tiles and remote example media require access to their external providers.
- Production site/example builds still report large JavaScript chunk warnings.
